# alg.like-terms: combining like terms (skill 2, after integers)

1. Generates `a·x + b + c·x + d`, e.g. `3x + 5 − x + 2`: x-terms −9…9, numbers −12…12, none 0; often x or −x (to test "x means 1x").
2. The answer is an EXPRESSION, e.g. `2x + 7`; children type it in any order (`7 + 2x` is also right).
3. Working: group like terms keeping signs `3x − x + 5 + 2`, then add them `2x + 7`.
4. Mistake **added-all-together**: adds x-terms and numbers together. `3x + 5 − x + 2` → `9x` (correct 2x + 7).
5. Mistake **dropped-sign**: drops the minus sign of the first negative term. `3x + 5 − x + 2` → `3x + x + 5 + 2 = 4x + 7`. Only when there is a negative term.
6. Mistake **x-as-0x**: treats x (or −x) as 0x. `3x + 5 − x + 2` → `3x + 0x + 5 + 2 = 3x + 7`. Only when there is an x or −x term.
7. The Teach checker accepts any line equal to the question that is a real step; the last line must be the simplest form (one x-term, one number).
8. The word problem is about biscuit packets at ₹x each, which gives positive answers like `6x + 30`.
9. Check by hand: is "drops the sign of the FIRST negative term" the common form of this mistake, or do children drop the sign of the x-term more often?
10. Check by hand: whether Class 7–8 children write `2x + 7` or `7 + 2x` (both are accepted), and the Hindi word व्यंजक.
