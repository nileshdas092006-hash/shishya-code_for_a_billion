## Rules, quoted from official sources (read 18 Oct 2026)
From JUDGING.md (github.com/karlmehta/code-for-a-billion/blob/main/JUDGING.md):
- "Every submission is scored out of 100 points across four criteria, weighted 25% each."
  1. Size of the problem: "How many citizens face this problem?"
  2. Severity of the problem: "The level of human suffering, or the economic loss"
  3. Quality of the solution: "How well the solution is designed and how effective it is"
  4. Proven impact: "Actual deployment data — real evidence of impact in the field (users reached, outcomes, measurable change)."
- "Ties are broken by Proven impact (criterion 4) — real deployment data wins — then Size of the problem"
- Eligibility: "Built using AgentFoundry (AF), the official IDE." · "Public GitHub repository with a working README." · "A demo link (live app or video) that judges can access." · "Submission issue filed before the deadline."

From codeforindia.org/hackathon:
- "There are no pre-set project briefs. Choose one of the ten areas ... define the problem you want to solve and how big it is"
- "Projects are released open-source (Apache-2.0 or MIT) to the Code for India GitHub organization ... You retain attribution as a contributor."
- "Students, professionals, and indie developers — solo or in teams."
- Side awards: "Best Use of AgentFoundry Agents" and "Best xSpan CareHub Integration" (CareHub is health only, so not for us)

  The GitHub README says $10,000 / $5,000 / $2,500 overall, $17,500 total.

  Financial Inclusion, Governance, Climate, Other.
- Organizers have not answered any Q&A in GitHub Discussions (including #13 "Does an existing project
  qualify if development continues in AgentFoundry?" and #18 "Does a project need to be built inside AgentFoundry?").

## AgentFoundry (AF) facts (agentfoundry.me, read 18 Oct 2026)
- It is an IDE (a code editor with AI built in), not a hosting service. Agents run on your own servers.
- Free editor; bring-your-own-key for Claude Code, Codex, Gemini and others; free SMART-Code credits (~1M tokens).
- Scaffolds agents for: Claude Agent SDK (TS/Python), Cursor SDK, Microsoft Agent Framework, Google ADK.
- One-click deploy to Vercel; AWS/Azure/GCP.
- The free tokens are for coding inside the IDE. They do NOT pay for the AI calls our live app makes.
