## Reporting a problem

Open an issue on the project's GitHub page (the **Issues** tab). Please say:

- what you did, step by step;
- what you expected to see, and what you saw instead;
- the screen width or device, if it is about how a page looks.

Never put a child's name, a student code, a class code, a teacher PIN or a recovery code in an issue. Issues are
public.

A school that wants a class deleted can do it on the class board ("Delete this class and all its data"); see
[PRIVACY.md](PRIVACY.md).

How to contribute code or a new skill: [CONTRIBUTING.md](CONTRIBUTING.md).
